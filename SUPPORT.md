# Support

Where to take a question, a problem or a vulnerability about the template.

- **A question about using the template**: read [the documentation index](docs/README.md) and
  [using the template](docs/template/using-the-template.md) first; if they do not answer it, open an
  issue and say which page you read.
- **Something broken or missing**: open an issue from the
  [bug report or feature request form](.github/ISSUE_TEMPLATE/bug_report.yml); the bug report asks for the
  version, the generation command and the fewest steps that reproduce the problem.
- **A vulnerability**: never in a public issue. Follow [SECURITY.md](SECURITY.md) and report it
  privately in a security advisory of this repository.
- **A change you want to make**: read [CONTRIBUTING.md](CONTRIBUTING.md) first, then open a pull
  request; the [code of conduct](CODE_OF_CONDUCT.md) applies to every space of this repository.
